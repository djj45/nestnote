## 1. 结论先行

- **形态**：纯 Web 应用（PWA）。电脑上用 Chrome 或 Edge 打开，也可以"安装为应用"，变成独立窗口；手机直接访问域名。一套代码三端通用。
- **数据核心**：每个页面（文档或画布）都是一个 **Yjs** 文档（CRDT）。前期只存在浏览器本地（IndexedDB）。做同步时，只需在服务器上跑一个 Yjs 同步服务，客户端加一个"连接服务器"的配置，**数据结构不用改**。多台设备同时编辑会自动合并，不会冲突；离线时的修改联网后也会自动合并。
- **文档编辑器**：Tiptap（基于 ProseMirror），做成类似 Notion 的块编辑，支持 `/` 菜单、拖拽块、Markdown 快捷输入、表格和代码块。
- **无限画布**：自己写一个轻量画布引擎（DOM + CSS 变换），不用 tldraw 或 Excalidraw，原因见 §3。
- **嵌套**：画布元素可以是"嵌入的页面"，文档里也可以插入"嵌入页面块"。被嵌入的页面会实时渲染，并且可以直接编辑。同一个页面可以嵌入多处，改一处，所有地方同步变化。
- **快捷键**：所有功能都注册为"命令"，快捷键只是命令的绑定，全部可以在设置里修改。另外配一个命令面板。
- **同步和部署（M5，已完成）**：Node 服务（Hocuspocus）+ SQLite，用 systemd 跑在你的服务器上，挂在现有 nginx 后面（HTTPS 用现有证书）。

> 顺带一提：开源的 AFFiNE 已经能做到"文档和白板互相嵌入 + 自托管同步"的大部分功能。如果你想要的是完全自己可控、能按自己的习惯深度定制（比如无限嵌套的交互、全部可自定义的快捷键），就按本方案自己做。

| 用自己的服务器同步 | Yjs 同步服务 + 资源文件服务，部署到你的服务器（§6） |

## 3. 技术选型

| 模块 | 选型 | 理由 |
|---|---|---|
| 语言 / 框架 | TypeScript + React + Vite | 生态最全，Tiptap 等库都对 React 有一流支持 |
| 数据 / 同步 | Yjs + y-indexeddb（本地）+ Hocuspocus（服务器） | 成熟的 CRDT 方案，本地优先，同步可以后插 |
| 文档编辑器 | Tiptap（ProseMirror） | 扩展性强，自定义块（嵌入页面、视频、文件）很方便，原生支持 Yjs 协同 |
| 画布 | 自研：元素用 DOM 渲染，视口用 CSS transform；连线和画笔用 SVG，笔迹用 perfect-freehand 生成 | 见下文 |
| UI 组件 | Radix UI / shadcn/ui + Tailwind，图标用 lucide | 无障碍支持好，容易定制 |
| 快捷键 | 自己写命令和按键管理器（底层可以用 tinykeys） | 需要支持作用范围、跨平台的 Mod 键和用户覆盖 |
| PDF 预览 | pdf.js | 标准方案 |
| 搜索 | 客户端自己建纯文字索引，中文按子串匹配（不用额外的库）；页面很多时再考虑服务器上的 SQLite FTS5 | 支持中文，不依赖服务器，离线也能搜 |
| 服务器（M5） | Node + Hocuspocus + SQLite（node:sqlite），挂在现有 nginx 后面，systemd 托管 | 单人使用，资源占用很小（运行时约 20–60MB 内存） |
| 测试 | Vitest + Playwright | 编辑器和画布的交互需要端到端测试 |

**为什么画布要自己写：**

- **tldraw**：体验最好，但它的 SDK 正式部署（放到 HTTPS 域名上）时需要许可证密钥。非商业项目可以申请 hobby 许可，但要保留"made with tldraw"水印，而且是逐个审核。没有密钥时，正式环境下编辑器几秒后就会停止渲染。放到你自己的域名上就属于"正式环境"。
- **Excalidraw**：MIT 开源，但它的定位是手绘白板，在元素里嵌入"可编辑的文档"或"另一张画布"很别扭。
- **自研的好处**：嵌套的难点在于事件路由，也就是内层画布的拖拽、滚轮、键盘焦点和外层画布之间怎么分配，这块必须完全可控。元素数据直接存在 Yjs 里，不用维护两份状态，也没有许可问题。
- **工作量可控**：元素用 DOM 渲染（而不是 Canvas 2D 或 WebGL），每个元素就是一个 React 组件：文本卡片就是一个小 Tiptap 编辑器，图片就是 `<img>`，视频就是 `<video>`。再加上"视口外的元素不渲染、缩小时降级为缩略图"，几千个元素没问题。
- **备选**：如果想更快出原型，可以先用 React Flow（MIT）做卡片画布。但它是"节点图"的思路，画笔、自由形状和嵌套的事件处理都会受限，不推荐作为长期方案。

## 4. 数据模型

### 4.1 页面（Page）

所有内容都是页面，页面只有两种类型：

```ts
type PageMeta = {
  id: string               // 全局唯一 ID（nanoid）
  type: 'doc' | 'canvas'
  title: string
  icon?: string
  parentId: string | null  // 在侧边栏里挂在哪个页面下（严格的树结构，不允许环）
  order: string            // 同级排序（分数索引）
  createdAt: number
  updatedAt: number
  trashedAt?: number       // 回收站
}
```

- 有一个"工作区索引"Yjs 文档，存放所有页面的 `PageMeta`、资源的元信息和用户设置。
- 每个页面的**内容**是一个独立的 Yjs 文档（id 就是页面 id），按需加载：只有被打开或者以嵌入形式出现在视野里时才加载。

### 4.2 文档内容

内容存在 `ydoc.getXmlFragment('content')` 里，由 Tiptap 直接读写。自定义节点：

- `pageEmbed { pageId, height }`：嵌入页面（文档或画布），实时渲染
- `pageLink { pageId }`：行内页面链接（输入 `[[` 或 `@` 触发）
- `image / video / audio / file / pdf { assetId, ... }`
- 另有表格、代码块、待办、引用、标注框（callout）、分割线，后期加公式

### 4.3 画布内容

```ts
// ydoc.getMap('elements')：id -> Y.Map
type CanvasElement = {
  id: string
  type: 'text' | 'sticky' | 'shape' | 'arrow' | 'pen' | 'image' | 'video'
      | 'file' | 'table' | 'embed' | 'frame'
  x: number; y: number; w: number; h: number; rotation: number
  z: string                // 层级（分数索引，同步时不会冲突）
  locked?: boolean
  parentFrame?: string     // 属于哪个分组框
  // 各类型自己的属性：
  // text / sticky / shape / table：一段 Y.XmlFragment 富文本（本身就是一个小文档）
  // arrow：起点和终点（可以绑定到元素的锚点，元素移动时箭头跟着动）
  // pen：点序列 + 笔触参数
  // image / video / file：assetId
  // embed：pageId + 内部视角 camera {x, y, zoom}（每个嵌入处各自记住自己的视角）
}
```

### 4.4 资源（图片、视频、文件）

- 按内容哈希（SHA-256）存储，同一个文件贴多次也只存一份。
- 本地阶段：二进制数据存在 IndexedDB；元信息（文件名、类型、大小、宽高、时长）存在工作区索引里。
- 同步阶段：资源上传到服务器的文件目录，客户端本地保留缓存；手机端按需下载。
- 图片会额外生成缩略图，画布缩小时显示缩略图，保证流畅。

### 4.5 "归属"和"嵌入"是两回事

- **归属（parentId）**：决定页面在侧边栏树里的位置，严格是一棵树。
- **嵌入（embed）**：任何页面都可以嵌入任何页面，可以嵌入多处，也可以互相嵌入（A 嵌 B，B 又嵌 A）。
- 在某个页面里"新建子页面"时，新页面归属于当前页面，并自动嵌入进来；把侧边栏里已有的页面拖进来时，只嵌入，不改变它的归属。
- 删除一个嵌入元素不等于删除页面。删除页面会把它放进回收站，原来嵌入它的地方显示"页面已删除"，并且可以恢复。

## 5. 功能设计

### 5.1 界面布局

```
┌────────────┬──────────────────────────────────────────┐
│ 侧边栏      │ 面包屑：画布A › 文档B › 画布C       [⋯]   │
│ 🔍 搜索     ├──────────────────────────────────────────┤
│ ⭐ 收藏     │                                          │
│ 🕘 最近     │         当前页面（文档 或 画布）            │
│ 📄 页面树   │                                          │
│   ├ 文档    │                                          │
│   └ 画布    │                                          │
│ 🗑 回收站   │                                          │
│ ⚙ 设置     │                                          │
└────────────┴──────────────────────────────────────────┘
```

- URL 的形式是 `/p/<页面id>`，浏览器的前进和后退可以直接用，链接也能收藏。
- 后期可加：多标签页、左右分屏。

### 5.2 文档编辑器

- 块编辑：段落、标题 1–3、无序列表、有序列表、待办列表、引用、代码块（带语法高亮）、分割线、标注框、表格、折叠块
- 用 `/` 斜杠菜单插入任何块，包括"新建嵌入文档"和"新建嵌入画布"
- 块左侧有拖拽手柄：可以拖动排序、转换类型、复制、删除
- Markdown 快捷输入：`# `、`- `、`1. `、`[] `、`> `、` ``` `、`---`
- 粘贴网页富文本、Markdown 文本、截图或文件时，会自动变成对应的块
- 把文件拖进来，会变成图片、视频、PDF 或文件块
- 支持导出 Markdown（嵌入的画布导出为图片）

### 5.3 无限画布

- **视图**：无限平移和缩放。平移可以用空格加拖动、鼠标中键或触控板双指；缩放可以用 Ctrl/⌘ 加滚轮或双指捏合。支持缩放到全部、缩放到选中，带小地图。
- **工具**：选择、抓手、文本卡片、便签、矩形 / 椭圆 / 菱形（形状里可以写字）、箭头连线（可以吸附到元素上）、画笔、橡皮、表格、插入文件、嵌入页面、分组框
- **操作**：框选和多选、拖动、缩放大小、旋转、对齐和等距分布、调整层级、编组、锁定、复制粘贴（包括跨页面）、撤销重做、对齐参考线
- **表格**：画布上的表格元素本质上是"只包含一张表格的小文档"，和文档里的表格用同一套编辑器：Tab 切换单元格、增删行列、拖动调整列宽、单元格内支持富文本。以后如果需要"数据库式表格"（字段类型、筛选排序、多种视图），再单独做。
- **卡片和页面互转**：画布上的文本卡片可以"提升为独立页面"，原来的位置变成这个页面的嵌入，之后可以在任何地方引用它。
- **导出**：PNG、SVG、PDF，可以导出选中区域或整张画布

### 5.4 无限嵌套（重点）

**渲染规则**

- 每次渲染嵌入内容时，都带上一条"祖先路径"。如果目标页面已经在这条路径里，就显示一张"循环引用"的占位卡片（可以点击打开），不再往下渲染。
- 实时渲染的深度上限默认是 3 层（可以在设置里改），更深的层级显示为"标题 + 缩略图"卡片，点击进入。
- 画布缩得很小时，嵌入内容自动降级为缩略图，放大后再恢复为实时可编辑。

**交互规则**

| 场景 | 默认状态 | 进入编辑 | 退出 |
|---|---|---|---|
| 文档里嵌文档 | 直接可编辑（类似"同步块"） | — | — |
| 文档里嵌画布 | 一个固定高度的窗口，可以拖动调整高度；滚轮不会劫持页面滚动 | 单击激活后，可以在窗口里平移、缩放和编辑 | 点击窗口外面或按 Esc |
| 画布里嵌文档 | 一张卡片，可以拖动、调整大小 | 双击进入文字编辑 | Esc |
| 画布里嵌画布 | 一个"窗口"，显示内层画布的某个视角 | 双击激活内层画布 | Esc |
| 任意嵌入 | — | 按 ⌘/Ctrl+Enter 或点右上角的"↗"，全屏打开该页面 | 面包屑或浏览器后退 |

- 打开嵌入页面时，面包屑会记录来路（画布A › 文档B › 画布C），可以一路退回去。
- 同一个页面嵌入在多处时，每一处各自记住自己的大小和视角，但内容是同一份。
- 后期可加：画布内"放大钻入"的动画（像缩放着走进一个房间）；反向链接面板（显示哪些页面嵌入或引用了当前页面）。

### 5.5 图片、视频、文件

| 类型 | 在文档里 | 在画布上 |
|---|---|---|
| 图片 | 图片块，可以调宽度、加说明 | 图片元素，后期支持裁剪 |
| 视频 | 内嵌播放器 | 内嵌播放器 |
| 音频 | 播放条 | 播放条 |
| PDF | 内嵌翻页预览 | 内嵌预览卡片，双击后可翻页 |
| Word / Excel / PPT 等 | 文件卡片（图标、名称、大小、下载） | 同左；上服务器后可以用 LibreOffice 转成 PDF 来预览（后期） |
| 网页链接 | 链接卡片，后期自动抓取标题和封面 | 同左 |

添加方式：粘贴（包括截图）、拖拽、`/` 菜单、工具栏按钮。

### 5.6 快捷键系统

**设计**

- 所有功能都注册成命令：`{ id, 名称, 默认快捷键, 作用范围, 执行函数 }`。
- 作用范围分为：全局、文档编辑中、画布、画布中选中了元素、画布内文字编辑中。同一个键在不同范围里可以绑定不同的命令。例如 `T` 在画布上是文本工具，在编辑文字时就是输入字母 T。
- `Mod` 会自动对应：Mac 上是 ⌘，Windows 上是 Ctrl。同一份配置两边通用。
- 设置页：列出所有命令，点击后直接按键录制，自动检测冲突，可以一键恢复默认，也可以导入导出配置。用户配置存在工作区里，同步上线后各设备保持一致。
- 命令面板（默认 `Mod+Shift+P`）：可以搜索并执行任何命令，同时显示它的快捷键，忘了快捷键时可以在这里找。
- Tiptap 的文字快捷键也走这套系统（根据用户配置生成），所以文字编辑的快捷键同样可以改。

**浏览器的限制（重要）**

在浏览器标签页里，下面这些组合键会被浏览器先拦截，网页拿不到：`Mod+N`、`Mod+Shift+N`、`Mod+T`、`Mod+Shift+T`、`Mod+W`、`Ctrl+Tab`，以及 Mac 上的 `⌘Q`。所以"新建笔记"的默认快捷键不能用 `Mod+N`。用户在设置页里选这些组合时会收到提示。

如果以后很想用 `Mod+N`，或者想要"系统级全局快捷键"（应用不在前台时也能呼出快速记录），可以再套一层 Tauri 外壳，打包成桌面应用。代码完全复用，体积十几 MB。这只是一个可选项，不影响现在的方案。

**默认快捷键（草案，全部可改）**

### 5.7 搜索

- 对标题和正文做全文搜索，包括画布卡片上的文字和表格内容，支持中文。
- 点击搜索结果直接跳到对应位置：文档会滚动到对应段落，画布会平移到对应元素并高亮。

### 5.8 手机端

- 手机访问 `https://你的域名`，登录后看到和电脑上相同的内容（需要同步功能上线后）。
- 和电脑一样可以编辑：侧边栏变成抽屉，画布支持单指平移、双指缩放、轻点两下编辑，触屏上不显示快捷键提示。
- 只读模式（M6 改为这样做）：设置 → 通用 里的开关，每台设备各自设置；开启后不能修改内容和页面结构，顶栏显示“只读”，点一下即可关闭。
- "添加到主屏幕"后像 App 一样全屏打开；登录后所有页面都会下载到本机，网页本身由 Service Worker 缓存，断网也能打开和编辑。

## 6. 同步与部署（M5）

```
 Mac / Windows / 手机 浏览器
          │  HTTPS + WebSocket（WSS）
          ▼
 ┌─────────────── 你的服务器 ───────────────┐
 │ nginx（现有，证书用现有的通配符证书）        │
 │   ├─ /            前端静态文件              │
 │   ├─ /sync        Hocuspocus（Yjs 同步）    │
 │   ├─ /api/assets  图片、视频、文件的上传下载 │
 │   └─ /api/auth    登录                     │
 │ 数据：SQLite（页面内容）+ 文件目录（资源）    │
 │ 每日备份（可以另外推送到其他位置）            │
 └──────────────────────────────────────────┘
```

- **同步方式**：客户端照常把数据存在本地的 IndexedDB，同时和服务器实时同步。断网时照常编辑，联网后自动合并；两台电脑同时改同一页也不会冲突或互相覆盖。
- **大文件**：视频等大文件分片上传，支持断点续传；服务器按哈希去重。
- **登录**：单个用户（或少量用户）用账号密码登录，配合长期有效的安全 Cookie，登录失败会限流。笔记是隐私数据，放在公网域名上必须有登录。
- **历史版本**：服务器定期给每个页面打快照，可以查看和恢复旧版本。
- **部署**：服务器是 Ubuntu 24.04、2 核、3.6G 内存、剩余约 32G 磁盘，没装 Docker。单人笔记用不着 Docker：Node 服务用 systemd 托管，数据放在固定目录里，更新时用一个脚本上传新版本并重启服务（`npm run deploy`）。
- **域名**：用自己域名下的一个子域名。服务器上 80/443 已被 nginx 占用（另有几个站点），所以在现有 nginx 上加了一个站点配置，没有另装 Caddy。

## 9. 风险与取舍

- **画布是最大的工作量**：自研意味着选择、变换、连线吸附、撤销等细节都要自己打磨。先保证核心手感（平移、缩放、选择、拖动），花哨的功能往后排。
- **嵌套的性能**：多层实时渲染会很重，要靠几件事来控制：视口外不渲染、缩小时降级为缩略图、深度上限、页面按需加载。
- **浏览器存储**：同步上线前，数据只存在一个浏览器里，清除浏览器数据就会丢失。应对办法是向浏览器申请"持久存储"，并提供一键导出备份。
- **浏览器快捷键限制**：见 §5.6，有需要的话以后用 Tauri 打包解决。
- **浏览器兼容**：电脑上推荐用 Chrome 或 Edge，体验最好；Safari（尤其是 iPhone 上）会做兼容，但以查看为主。
