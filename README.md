# Nestnote

自己的笔记软件：文档 + 无限画布，两者可以互相嵌套。浏览器打开，Windows、Mac、手机通用，通过自己的服务器同步。完整方案见 [docs/PLAN.md](docs/PLAN.md)。

部署到自己的服务器后（见下面“部署和服务器”），任何设备用浏览器打开自己的域名、登录即可。

## 在电脑上运行

需要 Node.js 20 或更新的版本。在终端里检查：

```bash
node -v
```

如果提示找不到命令，先安装 Node.js：到 https://nodejs.org 下载 LTS 版本安装，或者用 Homebrew 执行 `brew install node`。

然后在项目目录里安装依赖并启动：

```bash
cd ~/code/note
npm install
npm run dev
```

看到 `Local: http://localhost:5173/` 后，用 Chrome 或 Edge 打开这个地址。终端窗口保持开着，关掉就停止运行了。

如果 `npm install` 很慢或者失败，可以先换成国内镜像再装：

```bash
npm config set registry https://registry.npmmirror.com
```

## 现在能做什么（M0–M9）

- 侧边栏页面树：新建文档和画布、子页面、拖动排序、拖到别的页面上变成子页面、重命名、回收站
- 手机、平板上排序页面：按住一个页面约半秒，它浮起来后拖动。拖到别的页面上边缘或下边缘是放在它前面或后面，拖到中间变成它的子页面，拖到列表下方空白处移到最外层；拖到列表上下边缘会自动滚动
- 文档编辑：标题、列表、待办、引用、代码块（语法高亮）、标注框、表格、分割线、链接
- 输入 `/`（中文输入法下是 `、`）弹出插入菜单；选中文字出现格式工具栏
- 粘贴 Markdown 纯文本会自动转成标题、列表、待办、表格等；往标题里粘贴多行时，第一行做标题，其余进正文
- 光标在表格里时右侧有“表格”按钮，单元格里点右键也能打开表格菜单；表格操作也可以在设置里绑定快捷键
- 图片、视频、音频、任意文件：粘贴截图、从电脑拖进来、或在 `/` 菜单里选“图片 / 视频 / 文件”。图片和视频可以拖右边缘调宽度，双击图片看大图；PDF 可以直接在文档里预览
- 快捷键全部可以在 设置 → 快捷键 里修改；`⌘P` 跳转页面，`⌘⇧P` 命令面板
- 快捷键可以设成按键序列：录制时按完第一个键（要带 ⌘/Ctrl/⌥ 或是 F1–F12），一秒内再按第二个键，例如先按 `⌘K` 再按 `S`。用的时候按完第一个键，屏幕下方会提示在等第二个键，Esc 取消
- 设置 → 快捷键 会标出冲突的、会被浏览器拦截的快捷键，可以“只看这些”逐个处理；“导出 / 导入…”把改过的快捷键存成文件，换个浏览器导入（登录同步后各设备本来就通用）
- 设置 → 数据与备份：导出和导入备份（`.notebak` 文件，包含图片等文件），清理已经没用到的文件

画布（新建画布后）：
- 双击空白处写字；底部工具条可以放文字卡片、便签、表格、箭头、图片和文件（快捷键 T、N、⇧T、A）
- 拖动卡片移动，拖右边缘调宽度；空白处拖动框选；按住空格或用抓手工具（H）拖动画布；⌘/Ctrl + 滚轮或触控板捏合缩放
- 双击卡片编辑文字（和文档编辑器一样，支持 `/` 菜单、列表、表格），Esc 结束编辑
- 箭头工具从一张卡片拖到另一张，箭头会跟着卡片移动
- 右键菜单：复制一份、置顶/置底、便签颜色、删除；⌘Z 撤销、⌘D 复制一份、⌘C/⌘V 复制粘贴卡片
- 粘贴截图或文字会直接变成画布上的图片或卡片；文件拖进画布放在鼠标位置

文档和画布互相嵌套：
- 文档里输入 `/嵌入`：“嵌入新文档 / 嵌入新画布”会新建一个子页面嵌在这里，“嵌入已有页面”选一个别的页面；也可以从侧边栏把页面直接拖进文档
- 嵌入的文档直接在原处编辑（和整页打开是同一份内容）；光标在开头按 ↑、在末尾按 ↓ 就回到外面的文档
- 嵌入的画布是一个窗口：点一下进入，可以拖动、缩放、编辑；Esc 或点外面退出；拖窗口底边调高度。每个嵌入位置各自记住视角
- 画布上：工具条最右边的“嵌入页面”按钮、右键菜单“在这里新建文档/画布”，或者从侧边栏把页面拖到画布上。双击（或回车）进入编辑，Esc 退出；拖右下角调大小；缩得很小时只显示标题
- 画布上的文字卡片、便签可以右键“转为文档页面”：第一行做标题，内容搬进新文档，卡片原地变成这个文档的嵌入，连着的箭头保留
- 嵌入块右上角的 ↗ 或 `⌘/Ctrl + 回车` 打开整页，顶栏的面包屑会显示你是从哪层嵌入进来的
- 输入 `[[`（中文输入法下 `【【`）插入页面链接，页面改名后链接文字自动更新，点击打开；没有的页面可以直接新建
- 最多实时展开 3 层，再深的显示成一张卡片，点开看；页面嵌入了自己（或绕一圈嵌回来）会显示“循环嵌入”
- 删除嵌入块不会删除页面本身；被嵌入的页面进了回收站或被永久删除，嵌入处会显示提示，可以直接恢复

同步（M5）：
- 登录后，笔记在各台设备之间自动同步；两台设备同时改同一页也会自动合并，不会互相覆盖
- 断网时照常编辑，联网后自动同步。顶栏右上角显示状态：已同步 / 同步中 / 离线，点它进入 设置 → 同步
- 图片、视频等文件会传到服务器；别的设备打开时按需下载并缓存。超过 50MB 的视频和音频直接从服务器边下边播
- 页面右上角 ⋯ → 历史版本：服务器在页面有改动时自动存版本（最多 10 分钟一个），可以预览和恢复。恢复前的内容也会先存一个版本
- 设置 → 同步：立即同步、退出登录；“退出并清除本机数据”适合在别人的电脑上用完时
- 服务器每天 03:30 自动备份，保留 14 天

## 在手机和别的电脑上使用

用浏览器打开自己部署的网址（下面用 https://note.example.com 举例），输入用户名和密码登录。登录一次能保持一年（每次使用会自动续期）。

- 电脑：推荐 Chrome 或 Edge。第一次登录后，所有页面会在后台下载到这台电脑上，之后断网也能看和改
- 手机：iPhone 用 Safari，安卓用 Chrome。功能和电脑上一样，也能编辑。画布上单指拖动画布、双指缩放，轻点两下写字或编辑卡片、看大图；用底部工具条添加卡片
- 添加到主屏幕：iPhone 在 Safari 里点“分享”按钮 →“添加到主屏幕”；安卓在 Chrome 菜单里选“添加到主屏幕”或“安装应用”。之后从桌面图标打开，像 App 一样全屏显示
- 断网也能打开：打开过一次以后，网页本身会存在设备上，没网时也能打开、看和改笔记，联网后自动同步。没下载过的图片会在联网后显示
- 部署新版本后，开着的网页会提示“有新版本”，点“刷新”即可

## 画笔、手写笔和形状（画布）

- 工具条上的画笔（P）、橡皮擦（E）、形状（矩形 R、椭圆 O）。用画笔或形状时，工具条上方可以选颜色（6 种）和粗细（3 档），每台设备各自记住
- 平板上用手写笔（Apple Pencil 等）：有压感，笔迹自动平滑。不用先切到画笔，笔在空白处一落下就是写字；笔点到卡片上还是选中、拖动（设置 → 通用 →“手写笔”可以关掉）
- 用过笔以后，手指只负责拖动和缩放；笔在屏幕上时手掌碰到屏幕也不算。没有笔的手机上，选了画笔就能用手指画
- 先框选（或点选）元素再点橡皮擦（或按 E），会直接删掉选中的元素，提示条上可以撤销；没选中东西时点橡皮擦才切到橡皮擦工具
- 笔尾带橡皮的笔（Surface 笔等）翻过来就是橡皮擦；橡皮擦划过的笔迹、形状会变淡，松手时一起删掉，⌘Z 能撤销
- 每一笔、每个形状都是画布上的一个元素：可以选中、拖动、拉伸、复制、右键改颜色和粗细；矩形、椭圆只有点边框才选得中，框里面的卡片照样能点
- 拖形状时按住 Shift 是正方形 / 正圆；只点一下放一个默认大小的
- 导出图片时笔迹和形状一起画出来；导出 Markdown 时不包括手绘内容

## 搜索

- 全文搜索：`⌘⇧F`（Windows 上 `Ctrl+Shift+F`），或者侧边栏的“全文搜索”。会在所有页面的标题、正文、列表、表格、代码块、画布卡片和便签、图片和文件名里找；空格隔开的几个词都要出现
- 选中一条结果直接跳过去：文档会滚到那一段并选中搜到的字，画布会移到那张卡片并闪一下
- `⌘P` 只按标题找页面；在里面输入后也可以选“在所有页面的正文里搜索”
- 第一次打开搜索时要把页面读一遍，页面多的话会显示进度；之后只重新读改过的页面

## 导出和打印

- 页面右上角“…”菜单 → “导出为 Markdown”：文档、画布都可以。页面里嵌入的其它页面会一起导出成单独的 .md 并用链接连起来，图片和文件放在 assets 文件夹里，这时下载的是一个 .zip；只有一个文档、没有图片时直接下载 .md
- 画布：“导出为图片（PNG）”，有选中的元素时只导出选中的部分，颜色跟着当前的浅色 / 深色
- 文档：“打印 / 存为 PDF”，打印时只留正文；在打印对话框里选“存为 PDF”就是 PDF 文件

## 显示设置

- 浅色 / 深色：设置 → 通用 →“外观”，可选 跟随系统 / 浅色 / 深色；命令面板里也有“切换浅色 / 深色”
- 侧边栏：在电脑上拖动侧边栏的右边缘调宽度，双击右边缘恢复默认
- 文档宽度：设置 → 通用 →“文档宽度”，可选 窄 / 标准 / 宽 / 铺满。屏幕宽的时候选“宽”或“铺满”，两边空白少一些
- 这几项都只对当前设备有效

## 只读模式

点顶栏右上角的锁形按钮就能开关（也可以在 设置 → 通用 里开）。开启后只能看，不能改内容和标题，也不能新建、移动、重命名、删除页面，适合在手机上看笔记时防止误触。只对当前设备的这个浏览器有效，其它设备不受影响。开启时按钮变成蓝色的“只读”，再点一下关闭。命令面板里也可以用“开启 / 关闭只读模式”切换。

## 设置或修改密码

在 Mac 的终端里运行（会提示输入两次新密码，输入时不显示；账号不存在就新建，第一次部署后用它建账号）：

```bash
ssh -t 服务器 sudo note-passwd 用户名
```

改密码后，所有设备都要重新登录。同一个 IP 连续输错 5 次密码会被锁 15 分钟。

## 把只在 localhost 里的旧笔记传到服务器

浏览器按网址分开保存数据，`http://localhost:5173` 里的笔记在 https://note.example.com 上看不到，需要传一次：

1. 先在 `http://localhost:5173` 的 设置 → 数据与备份 里导出一份备份，留底
2. 停掉正在运行的 `npm run dev`（终端里按 Ctrl+C），换成连接正式服务器的方式启动：

   ```bash
   NOTE_SERVER=https://note.example.com npm run dev
   ```

3. 用平时存笔记的那个浏览器（Safari、Chrome 都可以）打开 `http://localhost:5173`，会出现登录页；登录后，本机所有页面和文件会自动传上去。等右上角显示“已同步”
4. 打开 https://note.example.com 核对。以后直接用这个地址就行

如果第 3 步出问题，也可以在 https://note.example.com 上登录后，在 设置 → 数据与备份 里导入第 1 步的备份，导入的内容同样会同步。

## 部署和服务器

```bash
npm run deploy
```

在 Mac 上一键完成：类型检查、构建、上传到服务器（用 ssh 和 rsync）、重启服务。

自己的服务器和域名写在项目根目录的 `deploy.local.env` 里（这个文件不提交到 git）。第一次使用时复制一份示例再改：

```bash
cp deploy.local.env.example deploy.local.env
```

服务器要求：Ubuntu / Debian，装好 Node.js 22 和 nginx，已有这个域名的 HTTPS 证书，Mac 能用 `ssh 主机名` 免密登录并且可以 sudo。第一次部署前运行一次 `bash scripts/setup-server.sh`（建用户、目录、systemd 服务、每日备份、nginx 站点），以后不用再运行；然后 `npm run deploy`，再用上面的 `note-passwd` 建账号。

服务器上的东西：

| 位置 | 内容 |
|---|---|
| `/opt/note/web` | 网页（静态文件，由 nginx 直接提供） |
| `/opt/note/server/server.mjs` | 同步服务（Node，打包成一个文件，服务器上不需要 npm install） |
| `/var/lib/note` | 数据：`note.db`（SQLite，页面内容、历史版本、账号）和 `assets/`（图片等文件） |
| `/var/backups/note` | 每日备份，每份是一个日期目录，里面有 `note.db` 和 `assets/` |
| `/etc/note/note.env` | 配置（端口、域名、目录），没有密码 |
| `/etc/nginx/sites-available/你的域名` | nginx 站点（证书用服务器上现有的证书） |

常用命令（在服务器上）：

```bash
systemctl status note                 # 服务状态
sudo journalctl -u note -n 100        # 服务日志（登录成功和失败都会记录）
systemctl list-timers note-backup     # 下次备份时间
sudo systemctl start note-backup      # 立即备份一次
```

从备份恢复（需要时再做）：`sudo systemctl stop note`，把某天备份目录里的 `note.db` 和 `assets/` 复制回 `/var/lib/note/`（`sudo chown -R note:note /var/lib/note`），再 `sudo systemctl start note`。

## 本地开发

- `npm run dev`：网页开发服务器（5173 端口）。会把 `/api` 和 `/sync` 转发给本机 8790 端口的同步服务；没有开同步服务时就是“只在本机使用”
- `npm run dev:server`：在本机跑同步服务（数据在 `apps/server/data`）。先运行 `npm run set-password -w @note/server -- 用户名` 设置一个本地账号
- `npm run typecheck`：前端和服务端的类型检查

## 目录结构

```
apps/web/src/
  app/        界面：布局、侧边栏、顶栏、首页、回收站、设置、命令面板
  pages/      页面视图和标题
  editor/     文档编辑器（Tiptap 扩展、斜杠菜单、工具栏）
  canvas/     无限画布（视口、卡片、箭头、工具条）
  embed/      文档和画布互相嵌套（嵌入块、页面链接）
  commands/   命令系统和快捷键
  store/      数据：工作区索引、页面文档、备份
  assets/     图片、视频等文件的存储
  sync/       登录、和服务器同步、文件上传下载
  lib/        通用工具
  styles/     样式
apps/server/src/
  server.ts   HTTP 接口和 Yjs 同步（Hocuspocus）
  auth.ts     登录、会话、限流
  assets.ts   文件上传下载
  history.ts  历史版本
  backup.ts   每日备份
deploy/       服务器上的配置文件（nginx、systemd、环境变量）
scripts/      部署脚本
```
